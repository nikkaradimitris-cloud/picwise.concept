# SEO Waves Specification

## Strategy Goal

Grow traffic through long-tail intent waves, not only through broad head keywords.

## Core Model

- Each landing targets a specific purchase-intent query.
- Many intent-specific pages combine into a larger traffic wave.
- Page copy must align tightly with the incoming query intent.

## Mandatory SEO Behavior

- Landing must confirm user query intent immediately.
- Decision output must remain 4 choices + 1 recommended.
- Content must prioritize decision closure, not generic blog-style expansion.
- No fake claims to inflate CTR/conversion.

## Query Targeting Guidance

- Prioritize long-tail and intent-rich query patterns.
- Include category-specific variants (tech, software, physical, financial/utility, high-trust).
- Query clustering strategy: TODO

## Page Structure Constraints

- Above-the-fold must surface decision content quickly.
- Avoid heavy non-decision content before primary choices.
- "More options" remains secondary.

## Quality and Risk Controls

- No keyword stuffing.
- No deceptive metadata.
- No fabricated stats/reviews/ratings.
- No commission-first recommendation framing.
