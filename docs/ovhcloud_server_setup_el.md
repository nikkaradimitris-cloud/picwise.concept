# Αγορά του server: OVHcloud VPS-4 (οδηγός για τον ιδιοκτήτη)

Γράφτηκε στις 23/10/2026, μετά την απόφαση του ιδιοκτήτη: «Πάμε με OVHcloud VPS-4,
γράψε μου τα βήματα αγοράς».

Οι τιμές και οι οθόνες ελέγχθηκαν μέσω αναζήτησης, γιατί οι σελίδες της OVHcloud δεν
ανοίγουν από τη συνεδρία. Αν κάτι στην οθόνη σου είναι διαφορετικό, στείλε μου
στιγμιότυπο οθόνης, **χωρίς κωδικούς και χωρίς κλειδιά**, και συνεχίζουμε από εκεί.

**Κανόνας για όλα τα βήματα:** κωδικοί, κλειδιά και ο σύνδεσμος του feed δεν γράφονται
ποτέ στη συζήτηση. Μπαίνουν μόνο στην OVHcloud και στο GitHub.

## Βήμα 0: το κλειδί πρόσβασης (πριν από την αγορά, 5 λεπτά)

Το κλειδί είναι δύο αρχεία:
- **το δημόσιο** μπαίνει στον server και επιτρέπει την είσοδο·
- **το ιδιωτικό** μπαίνει στο GitHub και το χρησιμοποιούν οι αυτόματες εργασίες για να
  στήνουν και να ενημερώνουν τον server.

Δεν το βλέπει κανείς άλλος.

**Σε Windows:** άνοιξε το PowerShell (Έναρξη, γράψε «PowerShell») και τρέξε, μία μία:

```
mkdir "$env:USERPROFILE\.ssh" -Force
ssh-keygen -t ed25519 -C "picwise-github" -f "$env:USERPROFILE\.ssh\picwise_github"
```

Όταν ζητήσει passphrase, πάτα Enter δύο φορές, χωρίς να γράψεις τίποτα. Οι αυτόματες
εργασίες δεν μπορούν να πληκτρολογήσουν κωδικό.

**Σε Mac:** άνοιξε το Terminal και τρέξε:

```
mkdir -p ~/.ssh
ssh-keygen -t ed25519 -C "picwise-github" -f ~/.ssh/picwise_github
```

Και εδώ, πάτα Enter δύο φορές στο passphrase.

Δημιουργούνται δύο αρχεία:
- `picwise_github.pub` είναι το **δημόσιο** (θα το χρειαστείς στο βήμα 3)·
- `picwise_github` είναι το **ιδιωτικό** (θα το χρειαστείς στο βήμα 5).

## Βήμα 1: λογαριασμός στην OVHcloud

1. Μπες στο ovhcloud.com. Η σελίδα `ovhcloud.com/en/` είναι η διεθνής, με τιμές σε
   δολάρια. Πάτα την υδρόγειο πάνω δεξιά, δίπλα στο «Support», και διάλεξε ευρωπαϊκή
   σελίδα στα αγγλικά με τιμές σε ευρώ: την Ελλάδα αν υπάρχει, αλλιώς την Ιρλανδία
   (`ovhcloud.com/en-ie/`). Αν η σελίδα σου πει ότι πρέπει να χρησιμοποιήσεις άλλη χώρα,
   κάνε ό,τι λέει.
2. Πάτα «Create an account» και δήλωσε:
   - **χώρα φορολογικής κατοικίας:** Ελλάδα· **νόμισμα:** ευρώ·
   - **είδος λογαριασμού:** Business, αν το PicWise είναι επαγγελματική σου
     δραστηριότητα. Αν έχεις ΑΦΜ για ενδοκοινοτικές συναλλαγές, τον δηλώνεις εκεί· για
     το πώς χρεώνεται ο ΦΠΑ, ρώτα τον λογιστή σου. Αλλιώς Individual.
3. Επιβεβαίωσε το email σου.

## Βήμα 2: παραγγελία του VPS-4

Στη μπλε μπάρα πάνω: **VPS & Dedicated Servers → VPS**. Διάλεξε:

| Επιλογή | Τι διαλέγεις |
|---|---|
| Μοντέλο | **VPS-4**: 8 vCores, 24 GB RAM, 200 GB NVMe |
| Τοποθεσία | **London** (αν δεν υπάρχει: Gravelines, Γαλλία) |
| Λειτουργικό σύστημα | **Ubuntu 24.04**, **χωρίς** πίνακα ελέγχου (ούτε cPanel ούτε Plesk) |
| Διάρκεια | **μηνιαία, χωρίς δέσμευση** για αρχή, περίπου €23,5 τον μήνα χωρίς ΦΠΑ |
| Επιπλέον επιλογές | καμία: το καθημερινό αντίγραφο ασφαλείας περιλαμβάνεται ήδη |

Η ετήσια προπληρωμή κοστίζει περίπου €20 τον μήνα. Αξίζει όταν δούμε ότι όλα δουλεύουν
σωστά.

## Βήμα 3: το δημόσιο κλειδί

**Αν η παραγγελία ζητάει «SSH key»:** επικόλλησε εκεί το **δημόσιο** κλειδί.

- Windows:
  ```
  Get-Content "$env:USERPROFILE\.ssh\picwise_github.pub"
  ```
- Mac:
  ```
  cat ~/.ssh/picwise_github.pub
  ```

Αντέγραψε όλη τη γραμμή που εμφανίζεται. Ξεκινά με `ssh-ed25519` και τελειώνει με
`picwise-github`.

**Αν η παραγγελία δεν ζητάει κλειδί,** προχώρα χωρίς αυτό και πες μου. Θα το βάλουμε
αμέσως μετά, με οδηγίες βήμα βήμα στη δική σου οθόνη.

## Βήμα 4: πληρωμή και παράδοση

1. Πλήρωσε.
2. Περίμενε το email παράδοσης («Your VPS is ready»). Συνήθως έρχεται σε λίγα λεπτά,
   το πολύ σε λίγες ώρες.

Το email έχει:
- τη διεύθυνση του server (**IPv4**, τέσσερις αριθμοί με τελείες)·
- το όνομα χρήστη (`ubuntu`)·
- έναν σύνδεσμο για προσωρινό κωδικό.

**Τον κωδικό δεν τον χρειαζόμαστε και δεν τον στέλνεις σε κανέναν.**

## Βήμα 5: τα «μυστικά» στο GitHub

Στο GitHub, άνοιξε το αποθετήριο `picwise.concept` και πήγαινε **Settings → Secrets
and variables → Actions → New repository secret**. Πρόσθεσε τέσσερα, ένα ένα:

| Όνομα (ακριβώς έτσι) | Τιμή |
|---|---|
| `SERVER_HOST` | η διεύθυνση IPv4 από το email |
| `SERVER_USER` | `ubuntu` |
| `SERVER_SSH_KEY` | το **ιδιωτικό** κλειδί, ολόκληρο (οδηγίες παρακάτω) |
| `AWIN_FEED_URL` | ο σύνδεσμος του feed, ο ίδιος με αυτόν της Vercel (πάρ' τον από το Create-a-Feed του Awin· η Vercel μπορεί να μη σε αφήνει να τον ξαναδείς) |

**Για το ιδιωτικό κλειδί,** αντέγραψέ το χωρίς να το δεις και επικόλλησέ το στην τιμή
του `SERVER_SSH_KEY`.

- Windows:
  ```
  Get-Content "$env:USERPROFILE\.ssh\picwise_github" -Raw | Set-Clipboard
  ```
- Mac:
  ```
  pbcopy < ~/.ssh/picwise_github
  ```

Πρέπει να περιλαμβάνει και τις γραμμές `-----BEGIN` και `-----END`.

## Βήμα 6: πες μου «έτοιμο»

Μόνο τη λέξη. Καμία διεύθυνση, κανένας κωδικός, κανένα κλειδί.

**Μετά (η δική μου δουλειά):**
1. Γράφω τις αυτόματες εργασίες του GitHub που στήνουν τον server: ενημερώσεις
   ασφαλείας, τείχος προστασίας, HTTPS, βάση δεδομένων.
2. Σου τις φέρνω για το «ναι» σου πριν μπουν στο main.
3. Το site τρέχει πρώτα στον server με τον σημερινό κώδικα, και το συγκρίνω με τη
   Vercel.
4. Η διεύθυνση του site αλλάζει μόνο όταν μου πεις εσύ. Μέχρι τότε η Vercel μένει όπως
   είναι.
